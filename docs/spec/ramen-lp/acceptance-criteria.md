## REQ-001: LP構成 🔵

**信頼性**: 🔵 *ユーザヒアリングより*

### Given（前提条件）
- Astro 6 + Tailwind CSS 4プロジェクトがセットアップ済み

### When（実行条件）
- ユーザーがLPのURLにアクセスする

### Then（期待結果）
- 「上州豚骨 中島屋」のLPが1ページ構成で表示される
- Header / Hero / こだわり / 店舗情報 / Footerの5セクションが順に表示される

### テストケース

#### 正常系

- [ ] **TC-001-01**: LP全体表示 🔵
  - **入力**: ブラウザでLPのURLにアクセス
  - **期待結果**: 5つのセクションが正しい順序で表示される
  - **信頼性**: 🔵 *ユーザヒアリングより*

- [ ] **TC-001-02**: 店舗名表示 🔵
  - **入力**: ブラウザでLPのURLにアクセス
  - **期待結果**: 「上州豚骨 中島屋」の店舗名がHeader/Hero/Footerに表示される
  - **信頼性**: 🔵 *ユーザヒアリングより*

## 非機能要件テスト

### NFR-001: パフォーマンス 🔴

**信頼性**: 🔴 *一般的なWeb標準からの推測*

- [ ] **TC-NFR-001-01**: LCP測定
  - **測定項目**: Largest Contentful Paint
  - **目標値**: 2.5秒以内
  - **測定条件**: 通常のネットワーク環境（4G相当）
  - **信頼性**: 🔴 *一般的なWeb Vitals基準から推測*

### NFR-101: レスポンシブデザイン 🟡

**信頼性**: 🟡 *既存実装のTailwindブレークポイントから妥当な推測*

- [ ] **TC-NFR-101-01**: モバイル表示（375px）
  - **検証内容**: 375px幅でレイアウトが崩れないこと
  - **期待結果**: コンテンツが1カラムで適切に表示される
  - **信頼性**: 🟡 *一般的なレスポンシブ対応から推測*

- [ ] **TC-NFR-101-02**: タブレット表示（768px）
  - **検証内容**: 768px幅でレイアウトが適切に切り替わること
  - **期待結果**: ナビゲーションがインライン表示になる
  - **信頼性**: 🟡 *既存実装のブレークポイントから推測*

- [ ] **TC-NFR-101-03**: デスクトップ表示（1280px）
  - **検証内容**: 1280px幅でレイアウトが適切に表示されること
  - **期待結果**: max-widthによるセンタリングが適用される
  - **信頼性**: 🟡 *既存実装から推測*

### NFR-201: アクセシビリティ 🟡
