**作成日**: 2026-03-14
**ヒアリング実施**: step4 既存情報ベースの差分ヒアリング

## ヒアリング目的

既存の二郎系ラーメンLP（豪天）からの全面リニューアルにあたり、新しいLP「上州豚骨 中島屋」の要件を明確化するためのヒアリングを実施しました。

**質問日時**: 2026-03-14
**カテゴリ**: 既存設計確認

## ヒアリング結果サマリー

### 確認できた事項
- 店舗名: 上州豚骨 中島屋
- コンセプト: 濃厚豚骨ラーメン専門店（東京の人気店）
- デザイントーン: 和モダン
- セクション構成: Header / Hero / こだわり / 店舗情報 / Footer
- こだわりポイント: スープ、食材・産地の2点
- 技術スタック: Astro 6 + Tailwind CSS 4（変更なし）
- 既存コードは全面作り変え

### 追加/変更要件
- 店舗名を「豪天」→「上州豚骨 中島屋」に変更
- メニューセクション削除
- コールガイドセクション削除
- デザイントーンをダーク系→和モダンに変更
- こだわりポイントを二郎系→濃厚豚骨（スープ・食材）に変更

### 残課題
- キャッチコピーの正式版（現在は仮コピー）
- 店舗情報の正式データ（現在は仮データ）
- 和モダンの具体的なカラーパレット（設計フェーズで決定）
- 使用する画像素材（現在はプレースホルダー）
