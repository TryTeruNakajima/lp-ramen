# ラーメンLP コンテキストノート

**作成日**: 2026-03-14

## 技術スタック

- **フレームワーク**: Astro 6
- **CSS**: Tailwind CSS 4（@tailwindcss/vite プラグイン）
- **フォント**: Google Fonts（Noto Sans JP: 400, 700, 900）
- **パッケージマネージャー**: pnpm
- **Node.js**: >= 22.12.0
- **ビルド**: 静的サイト生成（SSG）

## プロジェクト概要

- **店舗名**: 上州豚骨 中島屋
- **ジャンル**: 濃厚豚骨ラーメン専門店（東京）
- **サイト種別**: ランディングページ（1ページ構成）
- **デザイントーン**: 和モダン

## セクション構成

1. **Header**: 固定ナビゲーション（デスクトップ・モバイル対応）
2. **Hero**: フルスクリーン背景画像 + キャッチコピー
3. **こだわり（About）**: スープへのこだわり、食材・産地へのこだわり
4. **店舗情報（ShopInfo）**: 住所・営業時間・地図（仮データ）
5. **Footer**: コピーライト

## 既存コードベースからの変更点

- 既存の「ラーメン豪天」（二郎系）→「上州豚骨 中島屋」（濃厚豚骨）へ全面リニューアル
- メニューセクション: 削除
- コールガイドセクション: 削除
- デザイントーン: ダーク系 → 和モダン
- カラーパレット: 赤・黄・黒 → 和モダンに適したカラー（要設計）

## ディレクトリ構成

```
src/
├── components/
│   ├── Header.astro
│   ├── Hero.astro
│   ├── About.astro
│   ├── ShopInfo.astro
│   └── Footer.astro
├── layouts/
│   └── Layout.astro
├── pages/
│   └── index.astro
└── styles/
    └── global.css
public/
├── hero.webp
└── (その他画像)
```

## 注意事項

- 店舗情報（住所・営業時間等）はダミーデータで作成
- キャッチコピーはダミーで作成
- 画像はプレースホルダーまたは既存画像を流用
- 和モダンのデザイントーンに合わせたカラーパレット設計が必要
