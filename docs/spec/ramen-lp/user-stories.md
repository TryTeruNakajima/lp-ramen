## エピック1: ファーストインプレッション

### ストーリー 1.1: ヒーローセクションで店の魅力を伝える 🔵

**信頼性**: 🔵 *ユーザヒアリング（Heroセクション・濃厚豚骨コンセプト）より*

**私は** サイト訪問者 **として**
**LPにアクセスした際に、濃厚豚骨ラーメンの魅力的なビジュアルとキャッチコピーを目にしたい**
**そうすることで** 「上州豚骨 中島屋」への興味が湧き、詳細を読み進めたくなる

**関連要件**: REQ-020, REQ-021, REQ-022, REQ-023

**詳細シナリオ**:
1. ユーザーがLPにアクセスする
2. フルスクリーンの背景画像（濃厚豚骨ラーメン）が表示される
3. 店名「上州豚骨 中島屋」とキャッチコピーが視覚的に訴求される
4. CTAボタンで下部セクションへスムーズスクロールできる

**前提条件**:
- hero.webp画像が`public/`に配置済み

**制約事項**:
- キャッチコピーは仮テキスト（正式版は後日確定）

**優先度**: Must Have

---

### ストーリー 1.2: ヘッダーナビゲーションでセクション間を移動する 🟡

**信頼性**: 🟡 *既存実装・一般的なLP構成から妥当な推測*

**私は** サイト訪問者 **として**
**ヘッダーのナビゲーションから各セクションにジャンプしたい**
**そうすることで** 見たい情報にすぐアクセスできる

**関連要件**: REQ-010, REQ-011, REQ-012, REQ-101, REQ-102

**詳細シナリオ**:
1. 固定ヘッダーにナビリンク（こだわり・店舗情報）が表示される
2. リンクをクリックすると対象セクションにスムーズスクロールする
3. モバイルではハンバーガーメニューからナビゲーションする
4. スクロールするとヘッダーに背景が付く

**前提条件**:
- 各セクションにid属性が設定済み

**優先度**: Must Have

**備考**: モバイルハンバーガーメニューの必要性は既存実装の踏襲として推測

## エピック2: こだわり訴求

### ストーリー 2.1: スープへのこだわりを知る 🔵

**信頼性**: 🔵 *ユーザヒアリング（スープへのこだわり）より*

**私は** サイト訪問者 **として**
**中島屋のスープへのこだわりを知りたい**
**そうすることで** この店のラーメンを食べてみたいと思える

**関連要件**: REQ-030, REQ-032

**詳細シナリオ**:
1. 「こだわり」セクションにスクロールする
2. スープに関するこだわりの説明（タイトル + 詳細文）が表示される
3. 濃厚豚骨スープの製法や素材へのこだわりが伝わる

**前提条件**:
- こだわりセクションのテキストコンテンツが用意されていること

**優先度**: Must Have

---

### ストーリー 2.2: 食材・産地へのこだわりを知る 🔵

**信頼性**: 🔵 *ユーザヒアリング（食材・産地へのこだわり）より*

**私は** サイト訪問者 **として**
**中島屋が使う食材や産地（上州/群馬）へのこだわりを知りたい**
**そうすることで** 食材の品質への信頼感が高まる

**関連要件**: REQ-031, REQ-032

**詳細シナリオ**:
1. 「こだわり」セクションにスクロールする
2. 食材・産地に関するこだわりの説明（タイトル + 詳細文）が表示される
3. 上州（群馬）の食材を活かした豚骨ラーメンの特徴が伝わる

**前提条件**:
- こだわりセクションのテキストコンテンツが用意されていること

**優先度**: Must Have

## エピック3: 来店促進

### ストーリー 3.1: 店舗情報を確認して来店する 🔵

**信頼性**: 🔵 *ユーザヒアリング（店舗情報セクション選択）より*

**私は** サイト訪問者 **として**
**店舗の場所・営業時間・アクセス方法を確認したい**
**そうすることで** 実際に来店する計画を立てられる

**関連要件**: REQ-040, REQ-041

**詳細シナリオ**:
1. 「店舗情報」セクションにスクロールする
2. 所在地・最寄駅・営業時間・定休日・席数が表示される
3. 地図エリアで場所を確認できる

**前提条件**:
- 店舗情報データが設定されていること（仮データ可）

**制約事項**:
- 店舗情報は仮データ（正式版は後日確定）

**優先度**: Must Have

---

### ストーリー 3.2: モバイルからでも快適に閲覧する 🟡

**信頼性**: 🟡 *一般的なLP要件・既存実装から妥当な推測*

**私は** スマートフォンユーザー **として**
**スマートフォンでもストレスなくLPを閲覧したい**
**そうすることで** 外出先でも店舗情報を確認できる

**関連要件**: REQ-101, REQ-102, NFR-101

**詳細シナリオ**:
1. スマートフォンでLPにアクセスする
2. コンテンツがモバイル画面に最適化されて表示される
3. ハンバーガーメニューでナビゲーションできる
4. テキスト・画像が読みやすいサイズで表示される

**優先度**: Must Have

**備考**: モバイル対応の具体的なブレークポイントは設計フェーズで決定
