## タスク概要

既存の二郎系ラーメンLP（豪天）のコンポーネント・画像・設定を整理し、「上州豚骨 中島屋」LP構築の基盤を作る。不要なコンポーネント（Menu.astro, CallGuide.astro, Welcome.astro）を削除し、不要な画像（ramen.webp等）を整理する。package.jsonのプロジェクト名・descriptionを「上州豚骨 中島屋」用に更新し、既存のglobal.cssから二郎系カラー定義を削除する。

## 実装詳細

### 1. 不要コンポーネントの削除 🔵

**信頼性**: 🔵 *アーキテクチャ設計のコンポーネント構成に含まれないファイル*

以下のコンポーネントファイルを削除する:

- `src/components/Menu.astro` — 二郎系メニューセクション（新LPでは不要）
- `src/components/CallGuide.astro` — 二郎系コールガイドセクション（新LPでは不要）
- `src/components/Welcome.astro` — Astroデフォルトのウェルカムコンポーネント（不要）

### 2. 不要画像・アセットの整理 🔵

**信頼性**: 🔵 *新LPで使用しないファイル*

以下のファイルを削除する:

- `ramen.webp`（ルートディレクトリの二郎系ラーメン画像）
- `src/assets/astro.svg`（Astroデフォルトアセット）
- `src/assets/background.svg`（Astroデフォルト背景）

**注意**: `public/hero.webp` は新LPで使用する可能性があるため残す。

### 3. package.json更新 🔵

**信頼性**: 🔵 *REQ-001「上州豚骨 中島屋」のLP構築*

以下のフィールドを更新する:

- `name`: 「上州豚骨 中島屋」LP用のプロジェクト名に変更（例: `lp-nakajimaya`）
- `description`: 「上州豚骨 中島屋 - 濃厚豚骨ラーメン専門店ランディングページ」

### 4. global.cssの二郎系カラー定義削除 🔵

**信頼性**: 🔵 *旧テーマの定義はTASK-0002で新テーマに置き換える*

`src/styles/global.css` から以下を削除・整理する:

- 二郎系テーマのカラー変数定義
- 二郎系固有のスタイル定義
- Tailwind CSS 4の基本インポート（`@import "tailwindcss";`）は残す

### 5. index.astroのインポート整理 🔵

**信頼性**: 🔵 *削除したコンポーネントのインポートを除去*

`src/pages/index.astro` から以下を削除する:

- `Menu.astro` のインポートと使用箇所
- `CallGuide.astro` のインポートと使用箇所
- `Welcome.astro` のインポートと使用箇所（存在する場合）

## 基本的なテスト要件

- `pnpm dev` を実行し、開発サーバーが正常に起動すること
- ブラウザでページにアクセスし、エラーなく表示されること（内容は不完全でもよい）
- 削除対象のファイルが存在しないことを確認
- `pnpm build` でビルドエラーが発生しないこと

1. **現状確認**: 既存のファイル構成・インポート関係を確認する

8. **ビルド確認**: `pnpm build` でビルドエラーがないことを確認

## 注意事項

- `public/hero.webp` は新LPのHeroセクションで使用する可能性があるため削除しない
- Header.astro, Hero.astro, About.astro, ShopInfo.astro, Footer.astro は新LPで使用するため削除しない
- Layout.astro は TASK-0003 で更新するため、このタスクでは最小限の変更に留める
- global.css は TASK-0002 でアニメーション定義等を追加するため、既存の二郎系定義の削除のみ行う
- 削除前に `git status` で変更を確認し、意図しないファイルの削除がないことを確かめる
