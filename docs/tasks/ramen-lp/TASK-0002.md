## タスク概要

和モダンデザインを実現するためのテーマCSS（3パターン）とグローバルスタイルを作成する。Tailwind CSS 4の`@theme`ディレクティブを使用して各テーマのCSS変数を定義し、共通のアニメーション定義（fade-in-up, slide-in-left, slide-in-right, parallax, scale-in, text-reveal, line-draw）をglobal.cssに追加する。Noto Serif JPフォントの読み込みを設定する。

### 4. global.cssアニメーション定義 🔵

**信頼性**: 🔵 *アーキテクチャ設計のアニメーション一覧より*

`src/styles/global.css` に以下のアニメーション定義を追加する:

| アニメーション名 | 効果 | 対象 |
|----------------|------|------|
| `fade-in-up` | 下からフェードイン | セクション内テキスト・要素 |
| `slide-in-left` | 左からスライドイン | こだわりセクションのカード |
| `slide-in-right` | 右からスライドイン | こだわりセクションのカード |
| `parallax` | パララックススクロール | Hero背景画像 |
| `scale-in` | 拡大フェードイン | 画像・装飾要素 |
| `text-reveal` | 文字が現れる | キャッチコピー |
| `line-draw` | 線が描画される | 装飾線・セパレータ |

アニメーションはスクロールで表示領域に入った時に `is-visible` クラスが付与されて発火する設計（Intersection Observer API使用、実装はコンポーネント側で行う）。

`@keyframes` 定義と、`[data-animate]` 属性セレクタによる初期状態・表示状態のスタイルを定義する。

### 5. Noto Serif JPフォント設定 🔵

**信頼性**: 🔵 *アーキテクチャ設計のフォント設計より*

Google Fontsから Noto Serif JP（ウェイト: 400, 700, 900）を読み込む設定を行う:

```css
@import url('https://fonts.googleapis.com/css2?family=Noto+Serif+JP:wght@400;700;900&display=swap');
```

各テーマCSSの`@theme`ディレクティブ内でフォントファミリーを定義:

```css
@theme {
  --font-serif: 'Noto Serif JP', serif;
}
```

## 注意事項

- Tailwind CSS 4では`tailwind.config.js`ではなくCSS内の`@theme`ディレクティブでカスタムテーマを定義する
- 各テーマCSS内で`@import "tailwindcss";`は記述しない（global.cssで1回のみインポート）
- テーマCSSはページ単位でインポートする設計のため、各テーマは独立したファイルとする
- defaultテーマには `--color-text-invert` が追加で存在する（dark/lightテーマにはない）
- アニメーションの初期状態（opacity: 0, transform等）は`[data-animate]`セレクタで定義し、`[data-animate].is-visible`で表示状態に遷移させる
- フォントの`display=swap`を指定し、フォント読み込み中はシステムフォントでフォールバック表示する
