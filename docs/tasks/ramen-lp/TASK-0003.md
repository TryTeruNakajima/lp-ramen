## タスク概要

Layout.astroを更新し、Noto Serif JPフォント読み込み（preconnect含む）、title/meta description設定、テーマCSS受け取りprops対応を行う。3つのページファイル（index.astro, variant-dark.astro, variant-light.astro）を作成し、各ページが対応するテーマCSSをインポートしてLayout + 全コンポーネント（Header, Hero, About, ShopInfo, Footer）を配置する構成にする。index.astroから旧コンポーネント（Menu, CallGuide）のインポートを削除する。

## 実装詳細

### 1. Layout.astro更新 🔵

**信頼性**: 🔵 *アーキテクチャ設計のコンポーネント構成・SEO設計より*

`src/layouts/Layout.astro` を以下のように更新する:

#### Props定義

```typescript
interface Props {
  title?: string;
  description?: string;
}
```

- `title`: ページタイトル（デフォルト: 「上州豚骨 中島屋 | 濃厚豚骨ラーメン専門店」）
- `description`: meta description（デフォルト: 「東京で人気の濃厚豚骨ラーメン専門店『上州豚骨 中島屋』。上州・群馬の厳選食材と丁寧に炊き上げた豚骨スープが自慢です。」）

#### `<head>` 内の設定

- `<html lang="ja">` を設定（REQ-405）
- `<title>` タグにpropsのtitleを使用
- `<meta name="description">` にpropsのdescriptionを使用
- `<meta name="viewport">` を設定
- `<meta charset="UTF-8">` を設定
- Google Fontsのpreconnect設定:
  ```html
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
  ```
- global.cssのインポート

#### `<body>` 構造

- `<slot />` でページコンテンツを受け取る

### 2. index.astro更新（おまかせテーマ） 🔵

**信頼性**: 🔵 *REQ-004のセクション構成より*

```html

  <Header />

    <Hero />

  </main>
  <Footer />

```

`<main>` タグでメインコンテンツを囲み、セマンティックHTML構造を維持する（NFR-201）。

## 注意事項

- Layout.astroのpropsにはテーマCSSのパスを渡さない設計（各ページ側でテーマCSSを直接インポートする）
- 3ページのコンポーネント構成は同一（テーマCSSのみ異なる）
- コンポーネント内のスタイルはCSS変数を参照するため、テーマCSSの切り替えだけでカラーが変わる
- TASK-0001で不要コンポーネントが削除されていること、TASK-0002でテーマCSS・global.cssが作成されていることが前提
- Noto Serif JPフォントの`@import`はglobal.css側で行うため、Layout.astroではpreconnectのみ設定する
- variant-dark/variant-lightページのtitleには「（濃色版）」「（淡色版）」を付与し、クライアントが区別しやすくする
- 各コンポーネント（Header, Hero, About, ShopInfo, Footer）の内容実装はPhase 2以降のタスクで行う。このタスクでは配置のみ
