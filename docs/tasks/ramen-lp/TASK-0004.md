```html
<header class="fixed top-0 left-0 w-full z-50 transition-all duration-300" id="header">
  <div class="max-w-7xl mx-auto px-4 md:px-8 flex items-center justify-between h-16 md:h-20">
```

### ハンバーガーアイコンアニメーション 🟡

**信頼性**: 🟡 *REQ-011から妥当な推測*

```css
/* 3本線 → X のトランスフォーム */
.menu-line {
  transition: transform 0.3s, opacity 0.3s;
}
.menu-open .menu-line:nth-child(1) {
  transform: rotate(45deg) translate(5px, 5px);
}
.menu-open .menu-line:nth-child(2) {
  opacity: 0;
}
.menu-open .menu-line:nth-child(3) {
  transform: rotate(-45deg) translate(5px, -5px);
}
```

### スクロール時背景変化 🔴

**信頼性**: 🔴 *REQ-103より、ユーザヒアリングにない推測*

```javascript
window.addEventListener('scroll', () => {
  const header = document.getElementById('header');
  if (window.scrollY > 100) {
    header.classList.add('bg-base/80', 'backdrop-blur-md', 'shadow-sm');
  } else {
    header.classList.remove('bg-base/80', 'backdrop-blur-md', 'shadow-sm');
  }
});
```

### カラー設計（CSS変数使用） 🔵

**信頼性**: 🔵 *アーキテクチャ設計のテーマ方式より*

- スクロール時背景: `bg-base/80`（--color-base + opacity）
- モバイルメニュー背景: `bg-base/95`

## UI/UX要件

### ローディング状態

- ヘッダーはページロード時から即座に表示（遅延なし）

### エラー表示

- 該当なし（静的コンポーネント）

### モバイル対応

- 768px未満: ハンバーガーメニューアイコン表示、インラインナビ非表示
- 768px以上: インラインナビ表示、ハンバーガー非表示
- メニューオーバーレイはフルスクリーン、リンクは大きいタッチターゲット（48px以上）

### アクセシビリティ

- `aria-label="メニューを開く"` / `aria-label="メニューを閉じる"` の切替
- `aria-expanded="false"` / `aria-expanded="true"` の切替
- `<nav aria-label="メインナビゲーション">`
- キーボードでの操作対応（Tab, Enter, Escape）
- Escapeキーでモバイルメニューを閉じる

## 注意事項

- CSS変数を使用し、色のハードコーディングを避ける
- `z-50` でヘッダーが他の要素の上に表示されることを保証する
- スクロールイベントは `passive: true` で登録しパフォーマンスに配慮する
- モバイルメニュー展開時は `body` のスクロールを `overflow: hidden` で防止する
- スムーススクロールは `scroll-behavior: smooth` またはJS実装
