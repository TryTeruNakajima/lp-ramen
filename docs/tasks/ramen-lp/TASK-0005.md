### テキストリビールアニメーション 🟡

**信頼性**: 🟡 *REQ-021・アーキテクチャ設計のtext-revealより妥当な推測*

```css
[data-animate="text-reveal"] {
  opacity: 0;
  transform: translateY(20px);
  animation: textReveal 0.8s ease-out forwards;
}

@keyframes textReveal {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

- staggered delay: タグライン(0.3s) → キャッチコピー(0.6s) → サブコピー(1.0s) → サブテキスト(1.3s) → CTA(1.6s)
- ページロード時にトリガー（スクロール不要）

### パララックス効果 🟡

**信頼性**: 🟡 *アーキテクチャ設計のパララックス実装方式より妥当な推測*

```javascript
const heroBg = document.getElementById('hero-bg');

window.addEventListener('scroll', () => {
  const scrollY = window.scrollY;
  const heroHeight = heroBg.parentElement.offsetHeight;
  if (scrollY < heroHeight) {
    heroBg.style.transform = `translateY(${scrollY * 0.3}px)`;
  }
}, { passive: true });
```

- スクロール量の30%分だけ背景をY方向に移動
- Heroセクション高さを超えたら計算を停止（パフォーマンス考慮）
- `passive: true` でスクロールパフォーマンスを確保

## 注意事項

- `hero.webp` は `public/` ディレクトリに配置済みであること（TASK-0003で確認）
- CSS変数を使用し、色のハードコーディングを避ける
- 背景画像は `object-cover` で表示領域全体をカバー
- パララックスのスクロールイベントは `passive: true` で登録
- `prefers-reduced-motion: reduce` の場合、アニメーションとパララックスを無効化する
- テキストはオーバーレイ上に表示されるため、色は白系を基本とする（テーマ変数ではなく固定色）
- ただしタグラインとCTAボタンはテーマのアクセントカラーを使用
