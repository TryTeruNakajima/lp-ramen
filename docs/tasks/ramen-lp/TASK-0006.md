### スライドインアニメーション 🟡

**信頼性**: 🟡 *REQ-301・アーキテクチャ設計のアニメーション一覧より妥当な推測*

```css
[data-animate="slide-in-left"] {
  opacity: 0;
  transform: translateX(-60px);
  transition: opacity 0.8s ease-out, transform 0.8s ease-out;
}

[data-animate="slide-in-right"] {
  opacity: 0;
  transform: translateX(60px);
  transition: opacity 0.8s ease-out, transform 0.8s ease-out;
}

[data-animate="slide-in-left"].is-visible,
[data-animate="slide-in-right"].is-visible {
  opacity: 1;
  transform: translateX(0);
}
```

- Intersection Observer で `.is-visible` クラスを付与
- threshold: 0.1（要素の10%が表示されたらトリガー）

### 装飾線アニメーション 🟡

**信頼性**: 🟡 *アーキテクチャ設計のline-drawアニメーションより妥当な推測*

```css
[data-animate="line-draw"] {
  transform: scaleX(0);
  transition: transform 0.6s ease-out;
}

[data-animate="line-draw"].is-visible {
  transform: scaleX(1);
}
```

## UI/UX要件

### ローディング状態

- アニメーション開始前のカードは非表示（opacity: 0、transform適用）
- スクロールで表示領域に入った時点でアニメーション開始

### エラー表示

- 該当なし（静的コンテンツのみ）

### モバイル対応

- 768px未満: 1カラムレイアウト、カードは縦並び
- 768px以上: 2カラムグリッド（`md:grid-cols-2`）
- パディング調整: `p-8`（モバイル）→ `md:p-10`（デスクトップ）

### アクセシビリティ

- `<section>` にセクションタイトルを含む `<h2>` を配置
- カードの見出しは `<h3>` で構造化
- カードナンバー（01, 02）は装飾目的のため、スクリーンリーダーには `aria-hidden="true"` を設定する
- `prefers-reduced-motion: reduce` の場合、スライドインアニメーションを無効化
- 十分なコントラスト比を確保（テーマ依存、各テーマで検証）
