### fade-in-upアニメーション 🟡

**信頼性**: 🟡 _REQ-301・アーキテクチャ設計のアニメーション一覧より妥当な推測_

```css
[data-animate="fade-in-up"] {
  opacity: 0;
  transform: translateY(30px);
  transition:
    opacity 0.6s ease-out,
    transform 0.6s ease-out;
}

[data-animate="fade-in-up"].is-visible {
  opacity: 1;
  transform: translateY(0);
}
```

- 各情報項目にstaggered delay（0.1s刻み）を設定
- Intersection Observer で `.is-visible` クラスを付与

### モバイル対応

- 768px未満: 1カラムレイアウト、情報リスト→地図プレースホルダーの縦並び
- 768px以上: 2カラムグリッド（`md:grid-cols-2`）
- ラベル幅: `w-24`（モバイル）→ `md:w-32`（デスクトップ）

### アクセシビリティ

- `<dl>`, `<dt>`, `<dd>` による定義リストのセマンティックマークアップ
- `<section>` にセクションタイトルを含む `<h2>` を配置
- 地図プレースホルダーのSVGアイコンに `aria-hidden="true"` を設定
- `prefers-reduced-motion: reduce` の場合、アニメーションを無効化
