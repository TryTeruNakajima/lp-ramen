## 実装詳細

### 1. レスポンシブデザイン検証・調整 🟡

**信頼性**: 🟡 *実機・ブラウザでの目視確認が必要なため、設計書だけでは完全な保証ができない*

- ブレークポイントの検証:
  - モバイル: 320px〜767px
  - タブレット: 768px〜1023px
  - デスクトップ: 1024px以上
- 最小幅320pxで全セクションが正しく表示されること
  - テキストがはみ出さない
  - 画像が収まる
  - ナビゲーションが適切に折り畳まれる
- 最大幅2560px以上でコンテンツが中央揃え（`max-w-7xl`）であること
  - 背景は画面全幅に広がる
  - コンテンツ領域が中央に配置される
- 中間サイズ（375px, 414px, 768px, 1024px, 1280px, 1440px, 1920px）での表示確認

### 2. アクセシビリティ対応 🟡

**信頼性**: 🟡 *セマンティックHTMLの適切さは主観的判断を含むため*

- セマンティックHTMLタグの確認:
  - `<header>` — サイトヘッダー
  - `<nav>` — ナビゲーション
  - `<main>` — メインコンテンツ
  - `<section>` — 各コンテンツセクション
  - `<footer>` — サイトフッター
- 画像の`alt`属性が適切に設定されていること
  - 装飾画像: `alt=""`（空文字）
  - コンテンツ画像: 内容を説明するalt文
- ボタン・インタラクティブ要素の`aria-label`設定
- ハンバーガーメニューの`aria-expanded`属性
- フォーカスリングスタイルの設定:
  - キーボードナビゲーション時に視認可能なフォーカスインジケーター
  - `focus-visible`擬似クラスでマウスクリック時は非表示

### 3. prefers-reduced-motion対応 🔵

**信頼性**: 🔵 *メディアクエリの実装は明確*

- `@media (prefers-reduced-motion: reduce)` でアニメーションを無効化
  - `transition: none`
  - `animation: none`
  - `opacity: 1`（初期非表示の要素を表示状態にする）
  - `transform: none`
- パララックス効果の無効化
- スクロールアニメーションの無効化（コンテンツは即座に表示）

### 4. SEO設定の最終確認 🔵

**信頼性**: 🔵 *設定値は要件定義で明確に定義されている*

- `<html lang="ja">` が設定されていること
- `<title>`: 「上州豚骨 中島屋 | 濃厚豚骨ラーメン専門店」
- `<meta name="description">`: 店舗の特徴を簡潔に説明するメタディスクリプション
- `<meta name="viewport">`: `width=device-width, initial-scale=1`
- Open Graph / SNS共有用メタタグの確認（設定されている場合）

### 5. パフォーマンス確認 🟡

**信頼性**: 🟡 *LCPスコアは実測が必要*

- Hero画像の`<link rel="preload">`設定でLCP改善
- 画像の最適化確認:
  - WebP形式の使用
  - 適切なサイズ指定（width/height属性）
  - lazy loading（Hero以外の画像）
- 不要なJavaScript/CSSの排除
- Astroのビルド出力サイズの確認

### 6. ビルド確認・最終QA 🟡

**信頼性**: 🟡 *ビルドは成功するはずだが、全テーマの網羅的確認は実行時依存*

- `pnpm build` が警告・エラーなく成功すること
- ビルド成果物の確認（`dist/`ディレクトリ）
- 3テーマすべてでの最終品質確認:
  - `index.astro`（デフォルトテーマ）
  - `variant-dark.astro`（ダークテーマ）
  - `variant-light.astro`（ライトテーマ）
- 各テーマでの目視確認項目:
  - カラーコントラストが十分であること
  - フォント（Noto Serif JP）が正しく適用されていること
  - アニメーションが正常に動作すること
  - リンク・ナビゲーションが機能すること

### アクセシビリティ

- WCAG 2.1 AA準拠のカラーコントラスト比（テキスト: 4.5:1, 大文字: 3:1）

- `prefers-reduced-motion`でアニメーションが無効化されること
- フォーカス順序が論理的であること（DOM順序に従う）
